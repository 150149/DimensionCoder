# 代码流程图骨架

> 项目级共享资产（同一项目路径下的所有流程共用一份）：描述**项目代码怎么跑**——
> 入口到出口的所有路线与每个分支的走向条件。**不是本次任务的执行步骤流程图**。
>
> 更新方式 = 路线/分支变化时**替换对应那一条**（改哪条就重写哪条），不是往后追加新图新表、
> 不叠加历史版本。结构固定为 `## 流程图` 一个章节：不要新增其它 `##` 章节。

## 流程图

> 一张 Mermaid 图（`graph TD` / `flowchart`）：节点 = 关键函数/模块，边 = 调用/跳转，
> 分支处标注走向条件。项目复杂时用 `subgraph` 在**同一张图**内分区，不要拆成多个 `##` 章节。
> 图随代码演进整体重画，保持与当前实现一致。
