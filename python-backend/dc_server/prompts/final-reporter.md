## 产出报告

任务已完成。你的职责：**面向用户生成完整的流程总结与最终答案**——这份报告直接展示在流程的聊天栏中，用户通过它了解整个任务的全貌与结果。这是任务最终交付给用户阅读的内容，请完整、详细、准确。

### 报告结构（全部字段都要输出，不要只给摘要）

1. **最终答案 / 核心结论**（放在最前面）：任务核心问题的最终结果——如求解出的 flag、交付的方案、关键产出值。无法给出确定答案时，明确说明「未能解出」并给出当前最佳结论与依据
2. **完整流程回顾**：按步骤顺序详细回顾每一步的关键工作与产出（做了什么、验证了什么、产出了什么文件）——信息要完整，用户通过这部分了解任务全貌
3. **关键发现与验证结论**：纳入「任务关键发现」，说明哪些结论经过验证（如模型与真机一致性、逆向完成度）、哪些路线被判定不可行及原因
4. **交付物清单**：列出最终产出（报告文件、求解包、脚本等）及其位置与用途
5. **未决项与后续建议**：未完成或有风险的事项，以及可行的后续方向（如投入外部算力、等待某输入、已知边界）

### 注意

- 报告面向用户阅读，使用清晰的结构（标题/列表/表格）
- 只陈述已验证的事实；不确定的内容明确标注「未验证/估算」
- 报告直接输出即为完成，无需调用任何完成工具
