# 项目背景与约定

> 项目级共享资产：同一项目路径下的所有流程共用这一份。只写**项目级结论**，
> 不写本次任务的执行过程（那属于流程报告）。
>
> 更新方式 = 同类项**合并**、被取代的旧条目**删除**（替换式），一条一行、标注日期；
> 不是无限追加。结构固定为下面四个 `##` 章节：不要新增其它 `##` 章节。

## 项目信息

> 技术栈、目录结构、构建与运行方式、关键依赖、外部约束。每条一行。

## 开发规范

> 命名与分层、注释口径、测试要求、禁止事项。每条一行。与代码实际不符时校正旧条目。

## 经验教训

> 踩过的坑与规避方式，每条压成**一行**：现象 → 根因 → 做法。同类坑合并成一条，不逐次追加。

## 任务总结

> 每个流程收尾**一行**：这个流程做了什么、结论、未决项。不写过程流水。
